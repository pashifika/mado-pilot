# MadoPilot v0.1.0

MadoPilot v0.1.0 is the first developer-facing source, Rust API, C ABI, and C++
API baseline. It delivers one deterministic workflow over replayed frames so
integrators can exercise frame ownership, mapping, assets, template matching,
deadlines, cancellation, and language-boundary behavior before native desktop
automation is introduced.

The permanent `v0.1.0` tag is the canonical source identity for this release.
GitHub supplies source archives for that tag. No prebuilt library, installer,
package-manager formula, or registry package is included.

## Implemented workflow

The release supports the following end-to-end flow on
`x86_64-pc-windows-msvc` and `aarch64-apple-darwin`:

1. configure a deterministic replay source and the required OpenCV CPU backend;
2. discover and open a replay target;
3. acquire and retain an immutable frame;
4. describe a frame view and map its pixels to CPU memory;
5. load a validated asset package from directory, memory, or a bounded archive;
6. prepare a template and find it in that exact frame;
7. read a source-correlated match result; and
8. close and release owned resources.

The same workflow is available through:

- the idiomatic `mado-pilot` Rust facade;
- the separately versioned C ABI 1.0 and tracked C header; and
- the header-only C++ RAII wrapper over that C ABI.

The runnable Rust, C, and C++ examples are included in the source tree.

## Compatibility

- The product and Cargo package version is `0.1.0`.
- Public Rust names have completed their Phase 1 review, but the Rust API does
  not make its 1.0 stability promise yet. A pre-1.0 rename requires an ADR and a
  semantic version bump.
- The C ABI is independently versioned and frozen at ABI 1.0. Within ABI major
  1, released values, structure prefixes, field offsets, and function-table
  entries are not reordered or reinterpreted.
- The C++ wrapper declares no binary ABI of its own and inherits the released C
  ABI contract.
- Asset manifests carry their own schema version independently of the product
  and C ABI versions.

See the
[architecture baseline](https://github.com/pashifika/mado-pilot/blob/v0.1.0/docs/architecture.md),
[C ABI contract](https://github.com/pashifika/mado-pilot/blob/v0.1.0/docs/c-abi.md),
and
[C++ wrapper contract](https://github.com/pashifika/mado-pilot/blob/v0.1.0/docs/cpp-wrapper.md)
for the complete ownership and compatibility rules.

## Development prerequisites

The source selects Rust 1.97.1 through `rust-toolchain.toml` and uses the
committed root `Cargo.lock`.

Building the workspace requires a host-provided OpenCV 4 development
installation and a loadable libclang because the OpenCV adapter generates
bindings at build time:

- macOS: install Homebrew `opencv@4`; Xcode Command Line Tools provide libclang;
- Windows: extract the official OpenCV 4.14.0 prebuilt release, install LLVM
  22.1.8, and configure the documented discovery variables.

These are development-tree prerequisites, not bundled release dependencies.
Exact installation, discovery, license, and failure behavior is documented in
[third-party dependencies](https://github.com/pashifika/mado-pilot/blob/v0.1.0/docs/third-party-dependencies.md#opencv).

## Distribution scope

This release intentionally does not provide:

- crates.io packages; every workspace crate remains `publish = false`;
- prebuilt Windows or macOS libraries;
- ABI-major decorated release-library names;
- a CMake install/export set or pkg-config metadata;
- static libraries;
- bundled OpenCV or another native dependency; or
- an installer or package-manager integration.

The C and C++ examples consume the development tree through the included CMake
targets. Reserved packaging names remain future contracts and do not identify
files shipped by v0.1.0.

## Known limitations

MadoPilot v0.1.0 is not yet usable for real desktop automation. It does not:

- discover or capture a native window or display;
- probe Screen Recording or Accessibility permissions;
- inject pointer, keyboard, or text input;
- perform OCR;
- wait for a visual condition through watchers;
- schedule, coalesce, or diagnose streaming visual work;
- provide acceleration backends; or
- claim exact minimum Windows or macOS versions.

Those capabilities remain gated future work. Version one also excludes a GUI,
tray, overlay, editor, updater, workflow catalog, general scripting DSL, and
time-based scheduler.

## Security and privacy

The release performs no implicit network access, does not request screen or
input permissions, does not capture a desktop, and does not inject input. Asset
loading is network-free and rejects absolute paths, traversal, links, special
files, duplicate normalized entries, hash mismatches, and archive resource-limit
violations.

Ordinary logs and diagnostics exclude captured images, recognized text,
credentials, and other sensitive payloads by default. The host remains
responsible for authorization and the legality of any automation it builds.

## Verification evidence

Phase 1 is verified by:

- repository inventory and dependency-direction enforcement;
- formatting, clippy, workspace tests, doctests, and rustdoc with warnings
  denied;
- dependency license, advisory, and source policy;
- native Windows x64 and Apple Silicon macOS CI;
- native Rust, C, and C++ deterministic examples;
- Rust/C layout comparison and the frozen ABI 1.0 old-header fixture;
- OpenCV result evidence on both release targets;
- archive adversarial-fixture evidence; and
- four Phase 1 benchmark profiles with hard correctness and bounded-growth
  gates.

The performance profiles were measured twice on each named native host from
reviewed executable source state `8d7973e`; their second runs are committed and
all budgets pass. The commits after that executable state and through this
release-readiness change modify only ADR, architecture, performance-evidence,
and release documentation, so they do not alter the measured Rust/C workloads,
fixtures, dependencies, toolchain, or budgets.

The evidence and reproduction commands are tracked under
[`docs/evidence/`](https://github.com/pashifika/mado-pilot/tree/v0.1.0/docs/evidence),
[`docs/benchmarks/`](https://github.com/pashifika/mado-pilot/tree/v0.1.0/docs/benchmarks),
and
