# YYYY-MM-DD: Tuning topic

## Problem and intended outcome

Describe the observed problem or engineering objective and the affected metric.

## Change and reason

State what changed and why. Include old/new parameter or empirical-target values
with units when applicable; distinguish them from enforced runtime limits.

## Scope

Identify source/build or PR, platform/host, workload/fixture, observation mode and
relevant configuration. State exclusions needed to interpret the result.

## Evidence and effect

Link the exact command/method and raw output. Give comparable before/after values
with units, or explicitly state `not-measured`, `not-comparable` or `inconclusive`
and why. State only the effect supported by that evidence.

## Trade-offs and disposition

State retained, revised or reverted, the cross-metric costs, uncertainty and
remaining limitations. A target adjustment applies prospectively and never
regrades an earlier result. Link dated follow-ups without overwriting this
record's original outcome or evidence.
